# App Builds

Custom application builds, organized into a folder for each app.

- [Android Release System](Android-Release-System/README.md) — reusable fail-closed signing, verification, checksum, and permanent GitHub Release workflow for future Android apps.
- [RitschyMirror](RitschyMirror/README.md) — unofficial English translation of version 1.3.2. The original project is by RitschyRigz and is licensed under MIT.

Builds are generated using GitHub Actions on Windows or Linux as appropriate to the project. Finished installers/packages are available in the project's build artifacts or Releases after a successful run.
