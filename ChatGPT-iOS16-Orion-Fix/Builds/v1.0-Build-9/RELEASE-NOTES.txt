- If diagnostics resolve OFF, immediately removes those listeners, clears the buffer, and saves nothing.
- If diagnostics resolve ON, preserves any early bootstrap/module failure in the normal saved report.
- Keeps Build 8 compatibility polyfills and lightweight one-time snapshot behavior unchanged.
