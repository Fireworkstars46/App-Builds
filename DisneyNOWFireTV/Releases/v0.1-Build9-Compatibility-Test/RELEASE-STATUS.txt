Build 9 adds an optional privacy-safe Debug Mode to diagnose the Fire TV lag/playback problem without changing the Build 8 architecture.
Debug Mode defaults OFF. When enabled it records bounded app-owned diagnostics for page/load timing, WebView/main-frame errors, Media3 errors/state, media/DRM candidate counts, D-pad dispatch timing, navigation mode, performance mode, zoom, fullscreen state, Java heap use, and current main-frame host only.
Debug Snapshot shows current diagnostics. Export Debug Report writes the snapshot plus the last 200 privacy-safe app log lines to the app-owned debug folder. Debug counters can be reset from the menu.
Privacy boundary: no passwords, cookies, Authorization headers, provider tokens, full protected media/license URLs, query strings, device serials, or typed text are intentionally exported. WebView remote debugging remains disabled.
Build 8 native TV navigation, Performance Mode, whole-WebView zoom, experimental Media3 HLS/DASH/Widevine path, compatibility navigation modes, settings/data/cookies, and Silk fallback are preserved.
