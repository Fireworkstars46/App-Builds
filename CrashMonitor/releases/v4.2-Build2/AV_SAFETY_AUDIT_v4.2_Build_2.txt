INTENTIONALLY RETAINED - OBS enhanced crash-event detection uses DebugActiveProcess, WaitForDebugEvent,
ContinueDebugEvent, and DebugSetProcessKillOnExit(FALSE). This pre-existing OBS-only fallback preserves established
crash-time capture when OBS's own crash handling makes WER-only reporting unreliable. It remains scoped to
obs64.exe and does not write remote process memory, create remote threads, inject DLLs, or install hooks.

INTENTIONALLY RETAINED - Windows tar.exe is launched through CreateProcessW only after a dump is successfully
created, to losslessly compress/verify large dumps and preserve the established sharing workflow.

INTENTIONALLY RETAINED - WER LocalDumps HKLM changes use explicit UAC because Windows stores those settings
under HKLM. Normal app monitoring and Safe Self-Test remain non-elevated.

SmartScreen / antivirus note:
This build remains unsigned because the trusted project baseline is unsigned. Static review cannot promise
reputation-based SmartScreen/AV results on another machine. If Bitdefender reports a specific behavior, redesign
that behavior first rather than disabling protection or excluding the whole app/folder.
