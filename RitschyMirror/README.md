# RitschyMirror 1.3.2 — English build

An **unofficial English translation** of the original open-source [RitschyMirror](https://github.com/RitschyRigz/ritschy-mirror) by RitschyRigz (MIT license).

The Windows GitHub Actions workflow checks out upstream source at pinned commit `d9ca2cf61fe4b8a07a7cf171480473ae09fcd5c8`, translates UI strings with `Source/translate.py`, builds a self-contained Windows x64 application, and packages a normal setup EXE with Inno Setup.

- [Source / translation](Source/)
- [Builds / downloads](Builds/)
- [Windows build workflow](../../.github/workflows/build-ritschy-mirror.yml)

This build is unofficial and has not been endorsed by the upstream developer. Do not install until the workflow has finished successfully; Windows runtime functionality must still be checked on a Windows PC.
