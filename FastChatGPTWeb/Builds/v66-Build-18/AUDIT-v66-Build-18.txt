Audit decision
--------------
Build 17 does NOT fully satisfy the newest MASTER_RULES.md.

A real shared-settings stale-writer case remained:
1. Two Fast ChatGPT Web instances can be open with the same initial settings baseline.
2. Instance B can change and commit a setting.
3. Instance A can still hold the older value in memory.
4. Build 17 SaveAppSettings captured and rewrote the entire in-memory snapshot.
5. Therefore a later save/close by stale Instance A could revert an unrelated newer value committed by Instance B.

Build 17 already protected the special consolidation exit path by suppressing settings-save-on-close for newer instances, but that did not cover ordinary shared settings saves while Multi-instance mode remained ON.

The newest MASTER_RULES.md explicitly requires relevant multi-instance projects to prevent stale instances from overwriting newer committed shared settings/state and, when safely automatable, add matching stale-writer regression coverage.

An actual code/artifact change is required, so the separate Build advances from 17 to 18. Normal app version remains v66.
